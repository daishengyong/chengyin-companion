# 外部制片人交接指南

## 交付方式

发送方只需要给制片人两样东西：

1. `Chengyin-Companion-Episode-01-Producer-Handoff-*.zip`；
2. `11-PRODUCER-CODEX-START-PROMPT.md` 中的完整启动提示词。

制片人把 ZIP 放进一个新的工作目录，将 ZIP 和提示词一起交给自己的 Codex。Codex 先解压、校验和盘点，再结合制片人本机已有的视频、脚本、字幕、录屏或剪辑技能推进。

## 压缩包包含什么

- `00-READ-ME-FIRST.md`：10 分钟内启动项目的顺序。
- `01-CODEX-START-PROMPT.md`：与外部 Codex 对齐职责和阶段门的主提示词。
- `program-materials/`：节目总稿、逐镜表、录制清单、发布文案、环境准备和素材索引。
- `editorial-assets/app-resources/`：应用实际使用的最终视频、声音、图片与清单，可直接进剪辑软件。
- `editorial-assets/seedance-bts/`：经过隐私筛选的 Seedance 原始输出、联系表、尾帧、合约和质量记录，用于讲“怎么做出来”和展示迭代。
- `product-packages/`：可直接安装的 ZIP、DMG、源码改造包及校验清单。
- `generation-workbench/`：安全生成脚本、无 Key 模板、单镜头示例和计费保护说明。
- `producer-tools/`：环境检测器、Seedance Python 依赖与环境变量模板。
- `FILE-MANIFEST.tsv` 与 `SHA256SUMS.txt`：完整文件清单和包内校验。

## 故事主线

节目不是“AI 自动生成美女”，而是一个清晰的工程故事：

1. 先看成品：一个会动、会回应、能感知真实 Codex 完成事件的桌面伴侣。
2. 再拆架构：Codex 做导演和工程师，Seedance 做角色表演，预生成 TTS 做短反馈，SwiftUI 做透明桌面交互。
3. 解释关键难点：不是“放一张会晃的图”，而是视频资产、窗口形态、交互状态机、可靠完成事件、隐私和计费安全共同组成。
4. 真人现场安装：把预览包交给 Codex，完成安装、诊断和试玩。
5. 真人现场改一个小玩法：保持范围小，让观众看懂 Codex 如何检查、实施、验证和恢复。
6. 可选生成一条 Seedance 校准片：必须先展示成本、权利与人工确认门。
7. 结尾给观众两条路：直接安装体验，或用源码包改成自己的原创角色和玩法。

## Codex 与真人的分工

Codex 负责：

- 解包、校验、素材盘点、媒体技术检查；
- 结合已有技能重组脚本、镜头、录制批次和后期结构；
- 每批录制前给出极简操作单，录完后检查缺口；
- 生成转写、字幕草案、EDL/剪辑清单、章节和发布材料；
- 运行音画与成片质量检查；
- 明确任何偏离原始事实和权利状态的改编。

真人制片人负责：

- 确认平台、时长、主持风格和观众水平；
- 操作账号、输入 Key、确认付费和决定是否提交生成；
- 录制真人旁白、屏幕和必要补镜；
- 对人物表现、节奏、笑点、暧昧尺度、口型和整体观感做最终判断；
- 对公开发布权利、签名、公证和平台政策做最终批准。

## 阶段门

1. `preproduction_ready`：包已校验，事实表、环境和脚本已审完。
2. `awaiting_human_recording`：镜头锁定，等待真人按批次录制。
3. `rough_cut`：已有粗剪或 EDL，仍需真人审看。
4. `needs_human_review`：节奏、字幕、音频、人物一致性或事实需要确认。
5. `blocked_publish`：公开权利、许可证、Developer ID、公证或平台合规未解决。
6. `final_export_after_R19_R20`：真实视频审看与发布复核均通过后才允许导出公开成片。

任何 Codex 文字报告都不能替代真实视频的人工审看。

## 当前真实状态

- 节目总稿和录制材料已准备好，但还没有生成或剪出这期节目。
- 应用预览包、DMG 和源码改造包已完成本地校验。
- 当前应用是个人预览版，ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证。
- 现有角色媒体是原型素材，公开发行前仍要逐项完成角色、声音、音乐、字体与模型条款的权利复核。
- 随包素材足以完成节目。任何新的 Seedance、TTS、模型下载、云上传和发布都是可选动作，必须另行人工确认。

## 明确不包含

- 火山方舟 API Key、TOS AK/SK、账号 ID、资源包实例 ID或签名下载 URL；
- 原作者的完整云端账本、私人存储桶信息和任务 ID；
- 来源未解决的真人参考照片；
- 已经剪好的节目成片或 AI 主持人视频；
- 对公开商业发行权、模型输出再许可或平台审核结果的保证。

被排除的敏感或权利不明材料不是“遗漏”，而是有意的安全与发布边界。

## 建议的第一天流程

1. 15 分钟：Codex 校验包和环境。
2. 30 分钟：制片人与 Codex 锁定平台、时长、主持方式和主线。
3. 45 分钟：录冷开场、成品试玩和架构解释。
4. 45 分钟：录安装、诊断和一个小改造。
5. 30 分钟：补 Seedance 工作流、费用安全和权利说明；是否真实生成由制片人现场决定。
6. 30 分钟：Codex 回查缺镜、收音和屏幕隐私，再进入粗剪。
