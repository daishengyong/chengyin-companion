# 真人录制检查表

## 录制前一天

- [ ] 用演示账户或干净桌面，关闭邮件、日历、聊天和密码管理器通知。
- [ ] 把 Codex 任务标题、路径、用户名和 API Key 全部替换为演示信息。
- [ ] 确认安装包、DMG、源码包和 SHA256 清单在同一文件夹。
- [ ] 用隔离 HOME 跑过 portable install smoke。
- [ ] 从头执行一次节目中的主提示词，记录实际等待点，不临场第一次运行。
- [ ] 复核录制当天 Seedance 官方价格与规则；不复核就不在画面中出现数字。
- [ ] 确认展示的角色、声音、音乐、字体和 Logo 对本期公开用途有权利依据；否则标为内部预览并避免公开下载。

## 画面设置

- [ ] 主录屏 1920×1080、60 fps 或 30 fps 全程一致。
- [ ] Codex 字号至少 18–20 px；终端字号至少 20 px。
- [ ] 菜单栏可隐藏；Dock 自动隐藏；桌面只留节目文件夹。
- [ ] 伴侣默认从迷你头像开始，位置不遮 Codex 最后两行。
- [ ] Seedance 视频保持比例，不横向拉伸竖版旧素材。
- [ ] 单段等待超过 8 秒就准备后期加速，但保留开始、关键决策和结果。

## 声音设置

- [ ] 主持人独立麦克风录音；峰值建议约 -9 至 -6 dBFS。
- [ ] 伴侣原声音轨进入系统录音；不要让扬声器再次被麦克风收进去。
- [ ] 主持人口播时把伴侣素材降低约 8–12 dB；独立展示动作时恢复。
- [ ] 录一段 20 秒环境底噪。
- [ ] 不使用 macOS TTS 作为节目旁白。

## 必录的真实证据

- [ ] 安装器成功输出。
- [ ] 诊断器全部通过。
- [ ] 应用实际位于 `~/Applications`。
- [ ] AGENTS 只新增带标记的 Chengyin 区块，config.toml 未改变。
- [ ] 临时测试事件没有进入 live 目录。
- [ ] 一个真实 Codex 主任务完成后只庆祝一次。
- [ ] 卸载器只移除应用和自己加入的规则，个人数据默认保留。

## 后期检查

- [ ] 前 15 秒看得见结果，不先讲背景。
- [ ] 每 20–35 秒至少一次视觉变化。
- [ ] 命令、文件名和核心 Prompt 可暂停看清。
- [ ] 字幕不遮人物脸、Codex 状态或安装结果。
- [ ] 所有“自动”“免费”“本地”“可商用”表述都与证据一致。
- [ ] 公开发布前完成 R19 内容质量和 R20 权利/隐私复核。
