# ADR 0000: Short decision title

- Status: Proposed
- Date: YYYY-MM-DD
- Owners: maintainer names or GitHub handles

## Context

What user problem, constraint and existing behavior require a decision?

## Decision

State the chosen behavior, including data, permission, fallback and compatibility
boundaries.

## Alternatives considered

List serious alternatives and why they were not selected.

## Consequences

Describe product benefits, costs, migration, testing and reversal conditions.

## Verification

Name deterministic checks, recovery tests and observable acceptance criteria.
