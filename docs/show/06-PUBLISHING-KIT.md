# 节目发布素材包

## 推荐标题

默认：

> 我让 Codex 给自己做了个女朋友：会庆祝、催喝水，还能被你继续改造

技术向：

> Codex + Seedance 做桌面伴侣：从角色视频到一键安装的完整过程

克制向：

> 给 Codex 加一个有生命感的反馈层，我是怎么做的？

英文标题：

> I Gave Codex a Desktop Companion — Seedance, SwiftUI, and a One-Prompt Install

## 封面文字

只选一组，不要全部堆上：

- `CODEX 做了个伴侣`
- `任务完成，她会庆祝`
- `一个提示词，安装 + 改造`

封面构图建议：左侧 Codex 完成状态，右侧伴侣动作关键帧，中间用一条发光事件线连接。不要使用聊天气泡，突出“任务反馈”而非“AI 聊天”。

## 视频简介

> 这期把一个 Codex 桌面伴侣从效果、素材、代码到安装完整拆开：Codex 负责规划和实现，Seedance 负责角色动作与原生音画，预生成 TTS 负责大量短反馈，SwiftUI 把它们做成透明桌面角色。你可以先用预览包装好，再把完整提示词交给 Codex，从一个动作、提醒或小游戏开始改成自己的版本。
>
> 当前提供的是 Apple Silicon / macOS 14+ 的个人预览构建，尚未完成 Developer ID 签名、公证和公开媒体权利复核。请先阅读包内发行提示。

## 置顶评论

> 建议顺序：先装预览包体验 → 跑一次诊断 → 完成一个真实 Codex 任务 → 再下载源码包，只改一个小闭环。不要一开始就批量生成几十条视频。涉及 Seedance/Ark 付费调用时，先让 Codex列清调用次数、规格和成本，再人工确认。

## 60 秒切片结构

- 0–5 秒：任务完成庆祝；字幕“Codex 做完，她先开心了”。
- 5–15 秒：三形态 + 单击/甩动/游戏。
- 15–25 秒：五层架构快速闪现。
- 25–38 秒：双击安装器 + 诊断通过。
- 38–50 秒：母片 → 九种动作 → 原生音画。
- 50–60 秒：复制长提示词；CTA“先安装，再让 Codex 改一个玩法”。

## 不建议的表达

- “完全免费”：生成素材、签名发行和云 API 可能产生费用。
- “绝对不会误报”：应说当前协议只接受显式成功事件，并有测试与去重。
- “任何 Mac 双击就能装”：当前仅 Apple Silicon、macOS 14+，且未公证。
- “可以直接商用”：当前媒体与许可仍需公开发行复核。
- “复刻你喜欢的明星”：角色必须原创，不模仿可识别真人或公众人物。
