# Core 与 App 模块边界契约

简体中文 · [English](CORE-MODULE-BOUNDARY.md)

这份契约让贡献者可以在不启动窗口、播放器、网络或系统服务的情况下理解和验证澄音的
决策逻辑。`CompanionContracts` 负责确定性规则，`CompanionApp` 只负责读取系统事实、调用
Core、执行展示副作用。依赖方向只能是 App → Core，不能反向。

## 当前边界

Core 当前包含事件、共同工作日、注意力预算、体验仲裁、基于关系氛围的直接互动选择、
生活关心调度、用户主动播放的展开/回收计划、关系状态、窗口
布局、媒体投影、低动态效果、小游戏进度、备份和运行健康等稳定规则。无本机路径的投影创作回执也归
Core 所有，因此浏览器界面、事务应用器、测试与未来创作者前端共享同一个版本化焦点轨道／
安全区交接格式，不会各自发明私有结构。内容包画面选择与本地化无障碍文案也共用
`CompanionLocaleResolutionPolicy`：精确标签优先，
匹配书写系统优先于通用语言，通用语言优先于冲突地区；异常或超长运行时标签会在有界候选集内拒绝。
原先位于 App 层的 `CompanionLifestyleScheduler` 已迁入 Core；提醒种类、安静时段、活动状态、调度上下文、
策略和决策是显式跨模块接口。它当前的源码行数由审计回执中的 `requiredPolicyLines`
动态报告，不在文档中复制一个容易过期的数字。
`CompanionLifestyleMemoryV1` 与存储器现在统一负责隐私最小化的关心快照、有界恢复、单份
回滚副本、旧字段投影和显式删除语义；App 只保留一个专用 UserDefaults 适配器，ViewModel
不再自己维护七组互相独立的关心记忆字段。聚焦的运行协调器进一步统一会话预热、离开／返回
恢复、节奏策略绑定和送达记录，另一个展示映射器负责本地化状态文案；ViewModel 只注入有界
活动事实并执行返回的媒体副作用。
聚焦的内容操作协调器同样统一 MainActor 进度、安全作用域备份访问、可撤销删除回执和本地化、
无路径失败；事务内容库 actor 仍是唯一文件系统变更边界，ViewModel 只应用返回的库存快照。
纯数据的操作类型、成功投影和恢复回执放在独立聚焦模型文件中，新增结果形态不会继续暗中放大
副作用协调器。
`CompanionWorkdayStateV1` 现在使用同样明确的恢复边界：加载回执区分主记录、回滚副本和
安全默认值；聚焦的 App 适配器在保存失败时仍让真实任务反馈继续，并只报告稳定、无路径的
错误码，不暴露本地存储细节。
`CompanionWorkdaySignalTrustPolicy` 统一精确的生产者／版本白名单和失败关闭的终态投影：
只有内置 `terminal-events-v1` 发射器可触发成功庆祝；App Server 只保留其已声明的失败／中断，
未登记来源的终态声明一律降级为回复就绪。`CompanionEventIngress` 独立拥有有界信封解码、
不透明任务引用清洗与可信策略委托，但不具备文件系统、进程或网络能力；
`CompanionEventWatcher` 因此只拥有本地收件箱扫描、跨重启基线、去重与桥接健康。
`CompanionWorkdayExperiencePolicy` 负责无内容的
视觉、心情、状态、声明式内容提示、事件、关系奖励计划；普通进度、
取消和联动状态不会覆盖用户正在进行的主动互动、小游戏或前景媒体，进度心跳也永远不会变成
素材提示。任务开始、长任务和取消提示共用会话注意力预算，并可选择带最低版本门的内容包素材；
本地化、稳定事件触发别名与具体 UI 类型仍由聚焦 App 映射器负责。
互动氛围导演也已归 Core 所有：App 只注入小时、关系语气、氛围等级、心情和有界近期键，
再把返回的不透明时刻映射到展示媒体。
`CompanionUserPresentationPolicy` 还把主动播放的窗口规则显式化：头像点击和魔术棒会临时
展开舞台，游戏奖励会临时全屏，而仅声音模式绝不会改变窗口状态。App 会把旧版一次点击
意外留下的含糊“仅声音”状态迁移一次；魔术棒改用向上固定面板，不再依赖屏幕边缘的滚动菜单。
`CompanionPlayPaletteLayout` 是 AppKit 窗口与 SwiftUI 控件共用的自适应几何真值：完整画布
保留三列文字按钮；受限画布只收起解释文案、压缩类别与底部入口，并在需要时降为两列或一列。
所有动作无需 `ScrollView` 仍可触达，异常显示器数据则与窗口定位共用安全默认画布。
`CompanionPresentationSession` 统一持有临时返回形态及其所有者：连续点播会保留第一次点击
前的头像形态，内容包不能用自己的返回策略把用户主动互动留在大窗口；生成素材失败时也会在
同一次展开会话里接上本地回退，不再先缩回再弹开。
`CompanionPresentationLifecycle` 进一步把小头像点击、魔术棒、六种小游戏奖励、自动关心／任务
提示与内容包返回策略收敛到同一条无副作用指令；App 只执行返回的窗口变化，不再逐入口拼装规则。
聚焦的体验运行协调器进一步统一唯一注意力导演、带代际令牌的展示生命周期、待处理终态队列
和延迟回退交接。可信终态会替换低优先级队列项、在有界终态储备内扩容，并显式记录极端合并，
不再静默消失；旧计时器或失败视频也不能结束、覆盖更新的用户点播。头像与魔术棒的主动逗玩
还会开启有界的 45 秒注意力保护期：周期关心与报时留到下一次评估，结果就绪只作轻提示，可信
任务终态仍可靠保留。
聚焦的共同工作日运行协调器统一隐私最小日状态、本地事件桥轮询、可信策略投影和完成后回应
窗口。轮询重启不会重放已经消费的边界；关闭提醒时消费的事件不会稍后变成庆祝；旧回应计时器
也不能关闭更新的完成回应窗口。
无副作用的 `CompanionWorkdayApplicationProjection` 是工作日语义计划进入 App 可执行值的唯一
入口：响应就绪、失败或畸形的非终态计划都不能产生完成画面或关系奖励。工作日应用投影另有 140 行聚焦预算，不得拥有持久化、媒体、语音、窗口、进程或网络能力。
`CompanionTaskCompletionPolicy` 统一拥有任务庆祝等级、失败后恢复文案意图、关系语气上限和
四类直接手势回礼。它只输出有界关系键、正向奖励数值与语义动作，不接收任务内容，也不执行
持久化。无副作用 App 投影先完成本地化和动作映射，组合根再负责记录与播放。
`CompanionPetDragPolicy` 统一拥有拖拽结束后的分类优先级、有界姿态、回收延时和不透明关系键，
覆盖甩动、吸边、上举、轻碰与放稳五种反馈；计算前会归一化非有限值和极端指针数据。无副作用
App 投影只把语义计划映射成本地化文案、情绪、图标和已有声音提示，组合根只提交一次效果。
`CompanionPlaybackHealthAccumulator` 统一持有不透明播放令牌、恰好一次的终态计数、有界首帧
样本和 500ms 目标状态。App 只传入真实可见首帧的单调计时，不把视频路径、素材 ID 或内容包
身份带入诊断。
`CompanionRuntimeReadiness` 还统一划分“可安全自修复”和“必须人工处理”：只有事件目录权限收紧
与内容库中断事务恢复可以自动执行。应用／素材身份缺失、意外普通文件或符号链接、隐私声明异常
仍会明确留给用户处理；恢复过程不会替换应用、删除媒体、改变偏好或联网。
`CompanionPresentationEnvironment` 负责透明／影院／柔暗外观的无障碍回退，以及当前屏／主屏／
指定屏幕的确定性选择。AppKit 只提供有界技术标识与可见区域；指定屏断开后会安全回退，
人类可读显示器名称不会进入持久化。
`CompanionMicrogameSession` 统一负责六个内置小游戏的无内容规则：同一时间只允许一局、
有界倒计时、抓住／躲猫猫连击、固定动作顺序、画心容差、节拍命中窗口和投喂完成条件。
窗口、声音与触觉反馈仍属于 AppKit 适配层；聚焦的 App 运行协调器统一持有唯一可取消的
倒计时／节奏时间线和精确的游戏前返回上下文。结束游戏会清空会话进度，不制造连续打卡、
行为画像或隐藏持久化。`CompanionMicrogameWindowPolicy` 另外只接收选中显示器可见区域、
宠物装饰窗口尺寸、鼠标位置与不透明熵值：抓住我目标保持可触达，躲猫猫始终保留可点击探头，
不会连续重复同一边缘，损坏几何也不会把窗口送到其他显示器；AppKit 只应用返回坐标。
`CompanionMicrogameCompletionPolicy` 另外把每次胜利或结束映射为
无债务语义计划：胜利对应六个不同的正向纪念物与奖励演出，失败不扣关系值、不写负面记忆，
并统一精确返回节奏。聚焦 App 投影负责本地化，并在组合根执行音画副作用前应用用户选择的
关系语气上限。

Core 只能导入 `Foundation` 与 `CoreGraphics`，不得直接依赖 SwiftUI、AppKit、AVFoundation、
WebKit、Network、进程执行、浏览器或工作内容。它接收经过边界收缩的时间、布尔状态、
计数与枚举，返回可测试的决定，不读取任务标题、Prompt、代码、路径或用户文本。

## 机器门

运行基线审计：

```bash
python3 scripts/audit-core-module-boundaries.py --json
```

运行编译器解析边界审计。它让当前本地 `swiftc` 为四个已审阅 target 中的每个 Swift
源码输出语法树，再检查编译器给出的 import 节点和 27 个必需公开 Core 声明；它不会
类型检查或执行仓库源码：

```bash
python3 scripts/audit-swift-compiler-boundaries.py --json
./scripts/run-swift-compiler-boundary-smoke.sh
```

运行脚本回执所报告的完整正负例矩阵，包括策略回流 App、平台依赖、生活/关心与共同工作日记忆恢复/语言解析/共同工作日完成信任与展示策略/互动氛围/拖拽反馈/小游戏/用户展示/展示会话恢复/播放健康边界/有界运行恢复/媒体投影/投影创作/展示环境公开接口丢失、
设置界面回流、内容包契约重新合并、内容操作重新合并、小游戏运行态重新合并、体验运行态重新合并、共同工作日运行态重新合并、聚焦模块膨胀、组合层膨胀
和 Package 依赖断裂：

```bash
./scripts/run-core-module-boundary-smoke.sh
```

验证关心调度和其他核心策略的行为没有变化：

```bash
./scripts/run-core-policy-smokes.sh
```

运行稳定 Core 编解码、迁移、删除、恢复和决策矩阵：

```bash
swift run --disable-sandbox CompanionContractChecks
```

所有回执不包含用户名或绝对路径。失败使用稳定 `CORE_BOUNDARY_*` 代码，并给出移动策略、
移除副作用或拆分文件的恢复动作。

## 防回退预算

`CompanionViewModel.swift`、`ContentView.swift`、`CompanionSettingsView.swift` 与内容包验证器是迁移表面，
不是继续堆叠策略的默认位置。抽离互动策略、播放控件、视频播放器绑定、展示偏好／衬底、独立窗口设置、关心记忆、共同工作日持久化、展示会话所有权、序列播放界面、支持诊断和
AppKit 宠物手势桥接、确定性小游戏会话、共同工作日展示策略、生活关心运行／文案映射、聚焦媒体／回退阶梯、内容事务协调、唯一小游戏运行态、无副作用小游戏 HUD／状态投影、无债务小游戏结算策略／本地化奖励投影、纯任务完成／回礼策略与本地化投影、纯拖拽反馈策略与本地化值投影、带代际保护的体验运行态、统一共同工作日运行态、有限事实驱动的关心／工作双时钟、首次上手运行态、统一展示生命周期、有界关系记忆／反馈／冷却／播放历史协调、聚焦的完成回应／Codex 在场／关系回执／惊喜覆盖层、可跨重启恢复的手势发现协调器、统一展示运行协调器、带代际保护的宠物反馈运行态、拒绝过期回调的内容库运行态、类型化偏好迁移／修复存储、无能力设置备份投影、有界语音选择运行态、确定性小游戏窗口布局、聚焦内容序列会话和完成安全的工作日应用投影后，冻结的版本基线为 3576/5600、1269/3000、525/900 与
311/420。可执行审计回执是当前行数的唯一真值，逐文件报告实时行数、相对基线变化、剩余容量与饱和度；预算通过仍不能证明模块化已经完成。版本基线锁定 3576、1269、525 与 311 行，
后续变更在另一次审阅过的基线下调前必须保持不高于这些上限。审计还会拒绝把 `SettingsView`、动作／场景／待机／sprite 媒体阶梯或状态覆盖层视图合并回
`ContentView.swift`。状态覆盖层模块有 280 行聚焦预算，不得拥有窗口切换、调度、持久化或媒体选择。基线只应
随真实拆分单调下降。Core 单文件上限为 900 行，避免把巨型文件从 App 平移到 Core。
手势发现协调器有 140 行聚焦预算，只拥有不透明的已学习能力 ID、本地持久化与可取消提示计时；鼠标坐标、窗口、媒体、任务内容、语音和网络能力均留在边界外。

## 贡献流程

新增确定性规则时，先在 `CompanionContracts` 建立小型值类型，把系统输入收缩为有界事实，
再加入正常、安静时段、忙碌、损坏、重复、取消和恢复测试，最后才在 ViewModel 绑定。媒体
播放、窗口操作、UserDefaults 编排、系统事件读取和本地文件事务留在 App 适配层。

若要改变已经公开的调度类型、触发族、持久化字段、权限或依赖方向，必须先按照
[兼容策略](COMPATIBILITY.md)提供迁移与回退，并遵循[贡献者架构地图](CONTRIBUTOR-ARCHITECTURE.md)
和[贡献指南](../CONTRIBUTING.md)。安全修复可以立即收紧不安全输入，但不得静默改变稳定
错误码或让旧数据失去可执行恢复动作。

## 已知后续迁移

本契约没有宣称模块化已经结束。App 组合层仍然很大，部分反馈与媒体编排仍可继续拆分。
后续每次迁移必须减少或冻结 App 侧复杂度、保持内置回退、
通过中英本地化检查，并证明不会新增联网、麦克风、账户、收费、广告或自动分享。
