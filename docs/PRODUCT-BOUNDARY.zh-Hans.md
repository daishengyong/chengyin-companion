# 本地优先产品边界

[English](PRODUCT-BOUNDARY.md)

## 当前承诺

Chengyin Companion 的公开产品是一套完整、可长期使用的本地优先桌面伴侣。当前版本不包含收费、订阅、购买入口、强制账户、广告或自动分享。基础陪伴、内容包、小游戏、提醒、Codex 本地事件和创作者工具不会因时间或使用次数而停止。

允许用户明确触发的本地导出、备份和复制诊断，但应用不得自动上传、发布或分享任何内容。诊断必须继续排除用户名、绝对路径、任务正文、Prompt、代码、共同回忆、内容包标识和密钥。

## 兼容而非商业化

旧版内容包 schema 仍能解析 `paid` tier，目的只是避免把历史清单误判成未知格式。当前应用没有权益提供者、支付 SDK、结账链接或购买恢复服务，因此这类包会安全拒绝，不构成可用的收费通道。社区包和本地包继续通过来源、权利、签名状态、媒体完整性和运行时健康门管理。

## 历史研究隔离

早期商业化、支付和单位经济研究保留在开发者工作副本的私有研究目录中，作为决策历史，不属于公开克隆合同，不进入便携源码包，也不得从公开 README、贡献指南或架构入口链接。公开产品以后如需改变此边界，必须由所有者建立新的目标和独立审查，不能通过普通贡献悄悄加入。

## 可执行检查

运行当前工作副本边界检查：

```bash
python3 scripts/audit-product-boundary.py --scope development --json
```

在便携源码包或公开 Git 候选中运行：

```bash
python3 scripts/audit-product-boundary.py --scope public --json
```

检查回执只包含安全的相对路径、类别和行号，不包含命中的代码片段、环境变量值或绝对路径。该检查是可执行的防回退门，不是编译器 AST 证明，也不能代替最终许可证、素材权利、Developer ID、公证和人工公开发行批准。
