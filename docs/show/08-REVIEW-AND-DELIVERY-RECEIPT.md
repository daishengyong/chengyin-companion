## R20 发布合规

当前 `blocked_publish`，原因：

1. 根目录 MIT 已覆盖代码与随附软件文档，但 Starter 媒体、品牌与第三方素材的独立许可证尚未完成，因此不得把整个媒体仓库宣传为已完成 OSI 开源发行；
2. 现有角色视频、声音、音乐、字体与 AI 输出物仍需逐项建立公开展示和再分发权利记录；
3. 应用只有 ad-hoc 本地签名，未做 Developer ID 签名与 Apple 公证；
4. 没有干净实体 Mac 上的 Gatekeeper 首次打开录像与测试；
5. Seedance 价格与套餐规则属于动态信息，录制当天必须重新查官方页面；
6. “Codex”只能作为兼容性和教程描述使用，不得暗示 OpenAI 对本项目背书。
